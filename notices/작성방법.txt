  공지사항 쓰는 법
═══════════════════════════════════════════════════════════════

공지 하나를 올리려면 두 가지를 합니다.

  ① notices 폴더에 '본문 파일'을 새로 만든다
  ② notices/list.txt 에 한 줄을 추가한다

─────────────────────────────────────────────
① 본문 파일 만들기
─────────────────────────────────────────────

GitHub 저장소 화면에서

  notices 폴더 열기 → Add file → Create new file

파일 이름은 영문 소문자, 숫자, 붙임표(-)만 쓰고 .txt 로 끝냅니다.
날짜를 앞에 붙이면 나중에 찾기 쉽습니다.

  보기)  2026-11-20-welding-korea.txt

본문은 아래 규칙으로 씁니다.

  • 그냥 쓰면 문단이 됩니다. 빈 줄을 넣으면 문단이 나뉩니다.
  • 소제목은 줄 앞에 ## 를 붙입니다.          ## 행사 안내
  • 목록은 줄 앞에 - 를 붙입니다.             - 첫째 항목
  • 사진은   [사진] 파일경로 | 설명
  • 링크는   [링크] 주소 | 보여줄 글자
  • # 로 시작하는 줄은 화면에 나오지 않습니다. 메모용입니다.

본문 예시 ─────────────────────────────────

  11월 20일부터 22일까지 열리는 WELDING KOREA 2026에 참가합니다.

  ## 부스 안내

  - 장소 : 킨텍스 제2전시장
  - 부스 : C-204

  [사진] assets/news/welding-2026.jpg | 지난해 케미코 부스

  [링크] https://www.weldingkorea.com | 행사 안내 보기

  많은 관심 부탁드립니다.

────────────────────────────────────────────

다 쓰셨으면 아래 Commit changes 를 누릅니다.

─────────────────────────────────────────────
② 목록에 추가하기
─────────────────────────────────────────────

notices/list.txt 파일을 열고 연필 모양을 누른 뒤,
설명 아래 맨 윗줄에 한 줄을 추가합니다.

  2026.11.20 | 2026-11-20-welding-korea | WELDING KOREA 2026 참가 안내

  ↑ 날짜        ↑ 본문 파일 이름 (.txt 는 빼고)   ↑ 제목

Commit changes 를 누르면 1~2분 뒤 홈페이지에 올라옵니다.

─────────────────────────────────────────────
사진 올리기
─────────────────────────────────────────────

assets/news 폴더를 열고 Add file → Upload files 로 사진을 올립니다.
그런 다음 본문에서 이렇게 적습니다.

  [사진] assets/news/올린파일이름.jpg | 사진 설명

사진은 가로 1600픽셀 정도면 충분합니다. 너무 큰 사진은 홈페이지가
느려지니 미리 줄여서 올리십시오.

─────────────────────────────────────────────
공지를 내리고 싶을 때
─────────────────────────────────────────────

list.txt 에서 그 줄 맨 앞에 # 를 붙이면 화면에서 사라집니다.
글은 지워지지 않으니 나중에 # 만 떼면 다시 올라옵니다.
