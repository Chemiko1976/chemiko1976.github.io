보유재고 목록 작성 방법
=====================================

홈페이지의 "보유재고" 페이지에 나오는 표는 같은 폴더의 list.csv 파일 하나만
읽습니다. 그 파일을 고쳐서 올리면 홈페이지가 바로 바뀝니다.
HTML 을 만질 필요도, 저에게 요청하실 필요도 없습니다.


1. 어떻게 여는가
-------------------------------------
list.csv 는 엑셀에서 바로 열립니다. 파일을 두 번 누르시면 됩니다.

저장할 때가 중요합니다.

  파일 > 다른 이름으로 저장 > 파일 형식에서
  "CSV UTF-8 (쉼표로 분리)(*.csv)" 를 고르십시오.

  ※ 그냥 "CSV (쉼표로 분리)" 로 저장하면 홈페이지에서 한글이 깨집니다.
     목록에 두 가지가 나란히 보이니 UTF-8 이 붙은 쪽을 고르십시오.

저장을 누르면 "일부 기능이 손실될 수 있습니다" 라는 안내가 뜹니다.
표 하나짜리 파일이라 문제 없습니다. 예(계속)를 누르시면 됩니다.

파일을 열었을 때 글자가 □ 나 알 수 없는 기호로 보인다면,
지난번에 UTF-8 이 아닌 형식으로 저장된 것입니다.
그 파일은 버리시고 홈페이지의 stock/list.csv 를 다시 내려받아 쓰십시오.

메모장으로 열어 고치셔도 됩니다. 이때도 저장할 때 인코딩을
"UTF-8 (BOM)" 또는 "UTF-8" 로 두십시오.


2. 각 칸에 무엇을 쓰는가
-------------------------------------
맨 윗줄은 칸 이름입니다. 지우지 마십시오.

  재고번호   사내에서 쓰는 번호. 없으면 S-0001 처럼 순서대로 매기십시오.
             고객이 문의할 때 이 번호가 메일에 같이 담깁니다.
  제조사     utp (by voestalpine), VAC, Orbitalum 처럼 적습니다.
             이 값이 홈페이지의 제조사 선택 버튼이 됩니다.
  품명       제품 이름.
  규격       치수, 포장 단위 등. 예) Ø2.4 x 1000mm
  재질       해당 없으면 - 로 두십시오.
  수량       숫자만 적으십시오.
  단위       kg, 개, 조, 스풀, m 등.
  입고       입고 연도. 예) 2023
  비고       보관 상태, 개봉 여부, 단종 여부 등 구매자가 알아야 할 점.
             없으면 비워 두십시오.


3. 주의할 점
-------------------------------------
- 내용 안에 쉼표(,)를 쓰시려면 그 칸 전체를 큰따옴표로 감싸십시오.
    예)  S-0010,VAC,"포일, 절단품",폭 50mm,...

- '#' 으로 시작하는 줄은 홈페이지에 나오지 않습니다.
  당장 내리고 싶은 품목은 지우지 말고 줄 맨 앞에 # 을 붙이십시오.
  다시 올릴 때 # 만 지우면 됩니다.

- 가격은 칸을 두지 않았습니다. 홈페이지에 가격을 올리면 제조사와의
  대리점 계약(가격 정책)에 저촉될 수 있고, 경쟁사도 볼 수 있습니다.
  고객이 "견적 요청" 버튼을 누르면 품목 정보가 담긴 요청이 메일로 들어오니
  가격은 그때 개별로 회신하시는 편이 안전합니다.

- 지금 들어 있는 다섯 줄은 화면을 보시라고 넣은 예시입니다.
  비고에 (예시) 라고 적혀 있습니다. 실제 재고를 올리실 때 모두 지우십시오.


4. 올리는 방법
-------------------------------------
GitHub 에서 chemiko1976.github.io 저장소를 열고
stock 폴더로 들어가 list.csv 를 누른 뒤
연필 모양(Edit) 또는 Upload files 로 새 파일을 올리시면 됩니다.

올리고 1~2분 뒤에 홈페이지에 반영됩니다.
바뀌지 않으면 브라우저에서 Ctrl+F5 를 눌러 새로 고치십시오.


5. 고객 문의가 들어오면
-------------------------------------
보유재고 표의 각 줄에 있는 "견적 요청" 버튼을 누르면
자료·견적 요청 양식으로 넘어가면서 그 품목의 재고번호, 제조사,
품명, 규격이 문의 내용란에 자동으로 적힙니다.

고객이 보내면 chemiko@chemiko.net 으로 메일이 들어옵니다.
